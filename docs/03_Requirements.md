# Product Requirements for RoomLight

| ID  | Description                                                                 | Type           | Priority |
|-----|-----------------------------------------------------------------------------|----------------|----------|
| 1   | User can configure different lighting configurations                        | Functional     | MUST     |
| 2   | User can group configurations with rooms/areas (e.g. suites, corridors)     | Functional     | MUST     |
| 3   | User can centrally sync configurations to every room                        | Functional     | MUST     |
| 4   | System supports scheduled lighting based on time                            | Functional     | SHOULD   |
| 5   | CE marking compliance                                                       | Non-functional | MUST     |
| 6   | Basic centralized health check monitoring (online/offline)                  | Functional     | MUST     |
| 7   | Monitoring shows saved and deployed lighting settings                       | Functional     | SHOULD   |
| 8   | Advanced monitoring shows real-time status (e.g. local overrides)           | Functional     | COULD    |
| 9   | Mobile interface support                                                    | Functional     | COULD    |
| 10  | Standard wall-mount support                                                 | Non-functional | SHOULD   |
| 11  | Version control with point-in-time recovery                                 | Functional     | SHOULD   |
| 12  | Color temperature adjustment support                                        | Functional     | MUST     |
| 13  | Lights are dimmable                                                         | Functional     | MUST     |
| 14  | Movement sensor support                                                     | Functional     | SHOULD   |
| 15  | Lighting works even if central system is down                               | Functional     | MUST     |
